자체 ASH

수집기가 활성 세션을 직접 샘플링해 구간별 Top SQL·대기이벤트·세션을 재구성.Diagnostic Pack 불필요

✨

AI 튜닝 · 상황 요약

SQL·실행계획·스키마를 모아 Claude가 진단·인덱스·재작성을 스트리밍으로 제안. 개요 탭엔 현재 스냅샷을 3줄로 요약하는 버튼도.Claude APISSE 스트리밍비용 가드레일

🕐

인시던트 타임라인 · AAS 히트맵

스파이크·블로킹·데드락·KILL·보안·알림을 한 시간축에 통합. ASH는 대기클래스 × 시간 히트맵(OEM 스타일)으로.

⛔

락 / 데드락 추적

실시간 블로킹을 blocker/waiter SQL_ID와 함께 잡아 이력화하고, blocker를 바로 KILL. 데드락(ORA-00060)은 SQLite 영구 저장, 발생 시 탭 배지.

📧

이메일 알림

CPU 스파이크·블로킹·TS 포화 감지 시 원인 SQL_ID와 전문 포함 메일을 등록 수신자에게 발송.

🧭

세션 · Top SQL · 진행 작업

세션 상세(v$sesstat) 드릴다운, SQL 실행계획, RMAN/인덱스 등 대형 작업 진행률·남은시간. 넓은 표는 행 클릭 확장.

🖨️

리포트 · UX

현재 상태를 HTML/PDF 리포트로 내보내고, 다크/라이트 테마·밀도 토글·스마트 새로고침(상호작용 중 일시정지)까지.

💾

영구 저장 · 재시작 복원

지표·ASH·이벤트·감사로그를 SQLite(Node 내장)에 저장. 서버 재시작에도 차트·이력 유지. 이력 30일 보관 후 자동 삭제.

🔐

로그인 인증 · 감사 로그

DB 계정 기반 로그인(비밀번호는 SQL 내 비교, 앱이 평문을 다루지 않음), 시도 제한. KILL·설정변경 누가 했는지 기록.

📈

용량 · Prometheus

테이블스페이스 포화 예상일(D-day)·아카이브 로그·세그먼트 Top 소비. /metrics + 동봉 Grafana 대시보드로 연동.

가볍고 의존성이 적습니다

Thick 모드 oracledb + Node 내장 SQLite — 네이티브 빌드 부담 최소화

Node.js 18+ Express oracledb (Thick) node:sqlite nodemailer @anthropic-ai/sdk Vanilla JS SPA Oracle 11g (11.2)

3분 만에 시작

Node와 Oracle Instant Client만 있으면 됩니다

# 1) 저장소 클론
git clone https://github.com/Sangmoo/orama-agent.git
cd orama-agent/web

# 2) 의존성 설치 · 접속정보 설정
npm install
cp .env.example .env    # DB 접속정보 입력

# 3) 실행 → http://localhost:3900
npm start
